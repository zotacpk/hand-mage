# Hand Mage

เกมร่ายเวทด้วยมือจริงผ่านกล้อง (ต้นแบบ) เล่นบนเบราว์เซอร์ได้ทั้งมือถือและคอม

เล่นได้ที่: https://zotacpk.github.io/hand-mage

## วิธีเล่น
- **ชาร์จ**: หงายฝ่ามือแนวนอน ค้างไว้ ลูกไฟจะโตขึ้น
- **ยิง**: ตั้งฝ่ามือหันออก แล้วผลักไปทางศัตรู (ตำแหน่งมือซ้าย/ขวาใช้เล็ง)
- **โล่**: ผลักสองมือพร้อมกันโดยไม่ได้ชาร์จ

ไม่มีกล้องก็เล่นได้: โหมดแตะจอ (กดค้างเพื่อชาร์จ ปล่อยเพื่อยิง) หรือคีย์บอร์ด (Space ชาร์จ/ยิง, S โล่)

## เทคโนโลยี
- [three.js](https://threejs.org) สำหรับฉาก 3D
- [MediaPipe Hands](https://developers.google.com/mediapipe) จับมือ 21 จุด ประมวลผลในเครื่องผู้เล่นทั้งหมด
- ไฟล์เดียว `index.html` ไม่ต้อง build เปิดผ่าน GitHub Pages

## Mirror Mage (โหมดกระจก)
https://zotacpk.github.io/hand-mage/mirror.html

เห็นตัวเองเต็มจอแบบกระจก แล้วใช้นิ้วทำสามเหลี่ยม
- **▲ ปลุกพลัง**: นิ้วชี้สองข้างชนกันด้านบน นิ้วโป้งชนกันด้านล่าง ค้างไว้ครู่หนึ่ง
- **▼ สลายพลัง**: คว่ำสามเหลี่ยม (นิ้วโป้งอยู่บน)

เอฟเฟกต์: มือซ้ายมีประกายไฟพุ่งจากทุกนิ้ว + วง HUD, มือขวามีสายฟ้าและออร่า, และแสงวิ่งรอบขอบตัวจากล่างขึ้นบน (ใช้ MediaPipe Selfie Segmentation แยกร่างจากฉากหลัง)
